⚠️ Application intentionnellement vulnérable

Cette application contient de vraies vulnérabilités de sécurité à des fins pédagogiques : injection SQL, XSS, IDOR, path traversal, injection de commandes OS, MD5 pour les mots de passe, secrets hardcodés. À utiliser uniquement dans un environnement de TP isolé.

📡 Endpoints disponibles

  • GET/health — Health check
  • POST/api/register — Créer un utilisateur
  • POST/api/login — Se connecter
  • GET/api/tasks — Lister les tâches
  • POST/api/tasks — Créer une tâche
  • GET/api/tasks/<id> — Voir une tâche
  • PUT/api/tasks/<id> — Modifier une tâche
  • DELETE/api/tasks/<id> — Supprimer une tâche
  • GET/api/search?q= — ❌ Recherche (SQL + XSS)
  • GET/api/admin/users — ❌ Admin (clé en dur)
  • GET/api/admin/ping?host= — ❌ Ping (RCE)
  • GET/api/files?name= — ❌ Fichiers (path traversal)
  • GET/api/stats — Statistiques
